# QA-manual-portfolio-
Portfólio de QA Manual com casos de teste, planos de teste e relatórios de bugs.

## Sobre o projeto

Este projeto apresenta minha prática e aprendizado em QA Manual, utilizando uma aplicação web para realizar testes funcionais.

## Objetivos

- Criar um plano de testes
- Elaborar casos de teste
- Executar testes funcionais
- Identificar e documentar bugs
- Registrar evidências dos testes
- Praticar a organização de projetos utilizando GitHub

## Aplicação testada

**SauceDemo**

Aplicação web utilizada para prática de testes de software.

## Conteúdo do portfólio

- Plano de testes
- Casos de teste
- Execução dos testes
- Relatórios de bugs
- Evidências dos testes

## Ferramentas utilizadas

- QA Manual
- GitHub
- SauceDemo
- Jira
